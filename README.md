# Zombie Shooter

Survival Shooter • Unity • C#

Game Overview

A Unity survival shooter where the player fights off waves of zombies using first/third-person shooting mechanics. The project focuses on enemy detection, shooting mechanics, and survival pressure as the encounter builds up.

Core Gameplay Loop

Explore → Detect Zombie → Aim / Shoot → Survive → Progress

Game Development
Designed a survival-focused combat loop built around waves of enemies.
Focused on moment-to-moment tension between exploring and engaging threats.
Considered how enemy detection range and player health affect pacing.
Programming / Implementation
Implemented zombie detection and basic AI behavior (chase / attack).
Built shooting mechanics including aim, fire, and hit detection.
Added player health and damage systems.
Used C# and Unity gameplay scripting to tie movement, combat, and enemy logic together.
Development Challenge

How do you keep a wave-based shooter tense without making it feel unfair — balancing enemy numbers, detection range, and player resources?

What I Learned

How enemy AI, combat feedback, and health/damage systems combine into a single readable survival loop, and how to keep that loop tense but fair.
